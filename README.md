# Re-poster

Telegram-бот для агрегатора реферальных постов, конкурсов и розыгрышей.
Клиент платит за размещение, добавляет бота админом в свой канал и
помечает посты, которые хочет опубликовать в общем агрегаторе,
триггер-эмодзи (по умолчанию 🤑) в тексте поста.

## Как это работает

1. Владелец агрегатора (`OWNER_USER_ID`) запускает бот и владеет каналом-агрегатором (`AGGREGATOR_CHANNEL_ID`).
2. Клиент пишет боту `/start` в личке, нажимает «➕ Добавить канал» и пересылает любой пост из своего канала. Бот проверяет, что он добавлен туда админом, и привязывает канал.
3. Клиент оплачивает подписку через Telegram Stars (`PRICE_STARS_30D` за 30 дней) — или владелец продлевает её вручную из админки.
4. Когда клиент публикует пост с эмодзи `🤑` в тексте/подписи, бот делает `forward_message` (по умолчанию) или `copy_message` (если переключено) в канал-агрегатор.

## Режим репоста

- `forward` (по умолчанию) — пост уходит с пометкой «Forwarded from», подписчики видят источник.
- `copy` — пост выглядит как собственный пост агрегатора, без атрибуции.

Переключать может и клиент в своём меню, и владелец в админке (`/admin`).

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# заполнить BOT_TOKEN, OWNER_USER_ID, AGGREGATOR_CHANNEL_ID
python -m bot.main
```

Для приёма Stars-платежей в `@BotFather` ничего настраивать не нужно — `provider_token` для XTR оставляется пустым.

Бота нужно:
- добавить админом в канал-агрегатор с правом «Post messages» (для `copy_message`);
- клиенту добавить админом в свой канал (для получения `channel_post` и `forward_message`).

## Структура

```
bot/
├── main.py               # entrypoint, Dispatcher + routers
├── config.py             # env → Settings
├── db.py                 # SQLite, async через aiosqlite
├── keyboards.py          # inline-меню
└── handlers/
    ├── forwarder.py      # channel_post → проверка триггера → репост
    ├── client.py         # /start, регистрация канала, режим репоста
    ├── admin.py          # /admin: клиенты, продление, бан
    └── payments.py       # Telegram Stars: invoice, pre_checkout, success
```
